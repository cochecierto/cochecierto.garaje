# Runbook — desplegar el tema hijo de Garage

## Paquete

- Directorio fuente: `theme/cochecierto-garage-child/`
- Dominio: `garaje.cochecierto.com`
- Slug: `cochecierto-garage-child`
- Tema padre declarado: `twentytwentyfive`

## Orden

1. Desplegar y activar `CocheCierto Garage Core`.
2. Desplegar el tema hijo sin activarlo.
3. Confirmar que el tema padre está disponible.
4. Activar el tema hijo solo después de comprobar la plantilla y la portada.
5. Crear un producto ficticio en staging o como borrador.
6. Verificar ficha individual, archivo, enlaces permanentes y responsive.

## Seguridad

- No despliega WordPress completo.
- No sustituye la base de datos.
- No contiene credenciales.
- La activación del tema cambia la presentación pública y requiere aprobación explícita.
