# Contrato de proyecto

## Alcance

CocheCierto Garage es una plataforma WordPress independiente de recomendación y afiliación de productos para automoción en `garaje.cochecierto.com`. No tiene stock, logística, devoluciones ni checkout propio.

## Capas

`WordPress → tema hijo Garage → Garage Core → adaptador Amazon/futuros proveedores`

El tema presenta; el plugin propio contiene la lógica de catálogo; el proveedor externo gestiona la compra.

## Criterio de decisión

La landing debe reducir fricción y aumentar la comprensión antes del clic afiliado. Recomendar utilidad antes que comisión y dejar la decisión en manos del usuario.
