# Contribuir a CocheCierto Garage

## Antes de cambiar código

1. Leer `AGENTS.md`, `docs/constitution.md` y la spec activa.
2. Confirmar alcance, criterios de aceptación y riesgos.
3. No introducir credenciales, datos personales ni copias del WordPress completo.

## Cambios

- Mantener separado tema, lógica de negocio e integración de proveedor.
- Actualizar la spec antes de cambiar una decisión aprobada.
- Ejecutar las validaciones disponibles y documentar las no ejecutadas.
- Mantener commits pequeños cuando Git esté operativo.

## Afiliación

No publicar productos, precios, imágenes o enlaces de proveedor sin fuente, fecha y revisión editorial.
