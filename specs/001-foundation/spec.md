# 001-foundation — Fundación del proyecto

## Contexto

Garage dispone de WordPress en `garaje.cochecierto.com`, pero el repositorio oficial está vacío y aún no existe una base documental operativa propia.

## Problema

Sin una constitución, estructura SDD y responsabilidades claras, el proyecto puede mezclar el sitio principal, instalar dependencias prematuramente o implementar funcionalidades sin criterios de aceptación.

## Objetivo

Establecer la base documental, técnica y de coordinación para desarrollar Garage de forma independiente y trazable.

## Requisitos

- RF-001 — El repositorio debe identificar Garage como proyecto independiente.
- RF-002 — El proyecto debe declarar su repositorio oficial, despliegue objetivo y repositorio de referencia.
- RF-003 — Debe existir una Constitución con principios de independencia, transparencia, utilidad, privacidad, accesibilidad, arquitectura desacoplada y validación.
- RF-004 — Debe existir un agente principal `GARAJE` con responsabilidades, límites y subagentes definidos.
- RF-005 — La iniciativa debe registrar plan, tareas, validación y cambios.

## Fuera de alcance

- Publicar cambios en GitHub.
- Desplegar código en Hostinger.
- Configurar credenciales de Amazon.
- Importar productos reales.
- Crear contenido editorial definitivo.

## Criterios de aceptación

- La estructura inicial existe en la carpeta local.
- Los documentos no contienen secretos ni credenciales.
- Garage y CocheCierto principal aparecen como proyectos separados.
- El trabajo posterior puede comenzar desde una spec aprobada.
