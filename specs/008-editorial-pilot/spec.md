# Spec 008 — Piloto editorial de catálogo

## Objetivo

Preparar un primer lote de productos candidatos para validar el modelo editorial de Garage antes de incorporar ofertas de Amazon.

## Regla de publicación

Todos los registros permanecen en `draft` hasta que AMAZON verifique proveedor, identificador externo, imagen autorizada, compatibilidad, fuente y fecha.

## Criterios de aceptación

- Cada producto tiene una necesidad, un usuario recomendado, beneficios y límites.
- Ningún registro contiene precio, ASIN o disponibilidad inventados.
- El lote cubre primeras 72 horas, primeros 30 días y preparación de viajes.
- QA y AMAZON pueden revisar el lote sin modificar código.
